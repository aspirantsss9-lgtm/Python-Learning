# ДЗ — Взаимодействие между контейнерами

## Описание

Проект демонстрирует взаимодействие между контейнером веб-приложения и контейнером PostgreSQL.

В качестве веб-приложения используется FastAPI.

Приложение позволяет:

- просматривать записи из PostgreSQL;
- создавать новые записи;
- сохранять записи в PostgreSQL;
- получать сохранённые записи после перезапуска приложения.

PostgreSQL и FastAPI запускаются в отдельных Docker-контейнерах.

Для управления контейнерами используется Docker Compose.
