# Телефонный справочник

## Описание проекта

Телефонный справочник — консольное приложение на языке Python для хранения и управления контактами. Контакты сохраняются в файл формата JSON, благодаря чему данные не теряются после завершения работы программы.

Проект реализован с использованием архитектуры **MVC (Model–View–Controller)**.

---

## Основной функционал

Программа позволяет:

* открыть файл с контактами;
* сохранить контакты в файл;
* просмотреть список всех контактов;
* создать новый контакт;
* найти контакт по любому полю;
* изменить существующий контакт;
* удалить контакт;
* завершить работу программы.

### Model

Содержит бизнес-логику приложения.

Включает:

### Controller

Связывает модель и представление.

## Формат хранения данных

Контакты сохраняются в файл `contacts.json`.

Пример содержимого файла:

```json
[
    {
        "id": 1,
        "name": "Иван",
        "phone": "89001234567",
        "comment": "Друг"
    }
]
```

---

## Проверка данных

При создании и изменении контакта выполняется проверка введённых данных.

### Имя

Имя контакта не может быть пустым.

### Телефон

Номер телефона:

* не может быть пустым;
* может содержать только цифры;
* может начинаться с символа `+`;
* символ `+` допускается только в начале номера.

Примеры корректных номеров:

```text
89001234567
+79991234567
79991234567
```

Некорректные номера вызывают соответствующее пользовательское исключение.

---

## Обработка ошибок

В проекте реализованы пользовательские исключения:

* `PhoneBookError`
* `ContactNotFoundError`
* `InvalidContactError`
* `InvalidPhoneError`
* `FileReadError`
* `FileWriteError`

Это позволяет корректно обрабатывать ошибки без аварийного завершения программы.


Тесты проверяют основные функции приложения, корректность обработки ошибок, работу с файлами и различные варианты входных данных.

Также используются **параметризованные тесты** для проверки различных форматов имён и телефонных номеров.
