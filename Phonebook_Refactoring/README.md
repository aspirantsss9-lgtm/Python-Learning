# Телефонный справочник

## Описание проекта

Телефонный справочник — консольное приложение на языке Python для хранения и управления контактами.
Контакты сохраняются в файл формата JSON, благодаря чему данные не теряются после завершения работы программы.

---

## Основной функционал

Программа позволяет:

- открыть файл с контактами;
- сохранить контакты в файл;
- просмотреть список всех контактов;
- создать новый контакт;
- найти контакт по любому полю;
- изменить существующий контакт;
- удалить контакт;
- завершить работу программы.

---
### Model

Содержит бизнес-логику приложения.

Включает:

- Contact — описание контакта;
- PhoneBook — управление контактами;
- FileManager — чтение и сохранение данных;
- exceptions — пользовательские исключения.

---

### View

Отвечает за взаимодействие с пользователем:

- отображение меню;
- вывод сообщений;
- отображение контактов;
- получение пользовательского ввода.

---

### Controller

Связывает модель и представление.

Выполняет обработку действий пользователя и вызывает необходимые методы модели.

---

## Формат хранения данных

Контакты сохраняются в файл `contacts.json`.

Пример содержимого файла:

```json
[
    {
        "id": 1,
        "name": "Иван",
        "phone": "89001234567",
        "comment": "Друг"
    }
]
```

## Запуск программы

1. Открыть терминал.
2. Перейти в папку проекта.
3. Выполнить команду:

```bash
python main.py
```

---

## Использование программы

После запуска отображается главное меню.

```
1. Open file
2. Save file
3. Show all contacts
4. Create contact
5. Find contact
6. Edit contact
7. Delete contact
8. Exit
```

Пользователь выбирает необходимый пункт меню и следует инструкциям на экране.

## Обработка ошибок

В проекте реализованы пользовательские исключения:

- PhoneBookError
- ContactNotFoundError
- InvalidPhoneError
- FileReadError
- FileWriteError

Это позволяет корректно обрабатывать ошибки без аварийного завершения программы.
